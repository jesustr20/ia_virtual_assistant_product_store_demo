# ia_virtual_assistant_product_store_demo

Asistente de ventas multi-agente para una tienda de productos: agentes de Catálogo,
Ventas y Soporte coordinados por un router, con RAG sobre ChromaDB y autenticación JWT.
Proyecto de portfolio orientado a Backend Engineer AI.
